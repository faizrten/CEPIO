# Glossary

**Action** — A governed operation that changes CEPIO state or causes an external side effect.

**Actor** — Human, application, service or AI identity evaluated by CEPIO policy.

**Adapter** — Integration boundary translating between CEPIO and an external source or execution system.

**Binding** — Mapping between canonical CEPIO semantics and a platform representation such as Fabric IQ.

**Bitemporal** — Modeling with both valid time and transaction time.

**Canonical model** — The source-system-neutral semantic contract owned by CEPIO.

**CEPIO** — Common Energy & Process Industry Ontology.

**Decision** — A record connecting evidence/reasoning to a conclusion or recommended action.

**Event** — Immutable occurrence that may contribute to state changes.

**Function** — Typed calculation or reasoning operation that does not itself imply an external side effect.

**IRI** — Internationalized Resource Identifier; canonical semantic identity for ontology classes/properties/relationships.

**Kinetic plane** — Functions, decisions, actions, workflows and operational capability.

**MCP** — Model Context Protocol; used by CEPIO to expose governed tools to AI agents.

**Object** — Durable industrial or enterprise entity represented by CEPIO.

**Ontology module** — Versioned RDF/OWL package containing a coherent portion of CEPIO semantics.

**Operating abstraction** — Stable layer through which apps/agents interact with enterprise reality without coupling directly to source-system representations.

**Profile** — Customer/site/domain specialization of canonical CEPIO semantics.

**Projector** — Deterministic logic that derives state from immutable events.

**Property provenance** — Evidence showing where a property value came from and how it was transformed.

**Relationship** — Typed semantic connection between CEPIO objects.

**Semantic plane** — Objects, relationships, properties, events and state.

**SourceReference** — CEPIO reference to source-system evidence.

**State** — Current or historical operational condition of an object.

**Transaction time** — Time at which CEPIO recorded/learned a fact.

**Valid time** — Time at which a fact is true in the industrial domain.
