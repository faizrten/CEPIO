# Compounding Industrial Intelligence

CEPIO compounds industrial intelligence by promoting only reusable, evidence-backed capability discovered through domain onboarding.

## Flywheel

```text
Domain -> Competency Eval -> Domain Delta -> Generalization Review
       -> Capability Promotion -> Cross-Domain Regression
       -> Capability Registry -> Next Domain
```

The goal is not to make CEPIO larger. The goal is for each later domain to reuse more qualified capability and require less genuinely new platform logic.

## Capability Registry

The Capability Registry records what CEPIO can reliably do. It is separate from the Industry IQ Pack Registry (deployable runtime packages) and Skill Registry (runtime execution admission).

A capability includes maturity, validated domains, semantic contracts, competency references, evidence, reasoning/Skill context, runtime binding patterns and promotion provenance.

## Governance

Global capability promotion requires:

- two or more independent domains;
- `CORE` or `COMMON` target layer;
- complete configured regression survival;
- source-neutral evidence;
- human architecture approval.

Customer-specific data and customer profile artifacts cannot become evidence for global capability records.

## Metrics

The compounding report measures semantic reuse, reusable competency coverage, marginal gaps, cross-domain regression survival, promotion rate and registry maturity.

## Run

Use **Actions -> CEPIO Domain Onboarding -> Run workflow**. The action produces onboarding, compounding and proposed-registry evidence. A human-reviewed decision artifact is required to promote capability or release a domain; the workflow cannot self-approve.
