# ADR-0001: CEPIO is an operational ontology, not a catalog

## Status
Accepted

## Context
Energy enterprises already have taxonomies, canonical schemas, data catalogs and domain standards. Rebuilding another descriptive taxonomy would not create platform-level differentiation.

## Decision
CEPIO will model both semantic reality and kinetic capability. Core contracts include objects, relationships, events/state, functions, actions, decisions and policies. External effects are executed only through adapters behind governed action contracts.

## Consequences
- ontology definitions become production contracts;
- backward compatibility matters;
- security and audit are part of ontology design;
- source-system adapters remain replaceable;
- AI agents interact through authorized semantic tools rather than raw databases.
